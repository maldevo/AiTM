What good looks like

Measure behavior, not attendance.

Completion is a floor, not a finish line. The production program should be judged by retention, recognition, and reporting behavior.

Engagement

Module completion rate; time in module versus skip rate; return visits.

Retention

Knowledge check pass rate and a 90-day recheck score on core modules.

Behavior

Phishing simulation click-rate delta before and after training.

Reporting

Suspicious-message report rate from the trained cohort; time to report.
